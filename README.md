# B8A1: Problem Solving with TypeScript & OOP

This repository contains my solutions for **B8A1: Problem Solving with TypeScript & OOP**. The assignment focuses on fundamental TypeScript concepts, problem-solving techniques, and Object-Oriented Programming (OOP).

## Assignment Overview

There are two parts of this Assignment:

1) **Problem Solving:** Eight problems covering functions, optional parameters, union types, tuples, generics, interfaces, classes, inheritance, and asynchronous programming.
2) **Blog Writing:** Two technical blogs explaining important TypeScript concepts with examples.

## Blog Articles

1. [Type vs Interface in TypeScript: Understanding the Differences](type-vs-interface.md)
2. [Understanding Access Modifiers in TypeScript OOP](access-modifiers-typescript.md)
